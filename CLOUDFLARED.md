# Omaboard + Cloudflare Tunnel: мультиплеер через интернет

Друг не в твоём WiFi? Туннель Cloudflare превращает твою локальную доску
(`localhost:8090`) в публичную **https**-ссылку. Другу нужен только браузер —
приложение скачивать не обязательно.

Quick-туннели бесплатны и **не требуют регистрации**.

---

## 1. Установка cloudflared

**Arch / Omarchy** (пакет в официальном репозитории `extra`):

```bash
omarchy pkg add cloudflared
# или: sudo pacman -S cloudflared
```

**Windows:**
скачай релиз с GitHub —
<https://github.com/cloudflare/cloudflared/releases/latest>,
файл `cloudflared-windows-amd64.exe`, положить куда угодно и переименовать
в `cloudflared.exe`.

**macOS:**

```bash
brew install cloudflared
```

Проверка: `cloudflared --version`

---

## 2. Запуск (два терминала)

**Терминал 1 — сама доска:**

```bash
./omaboard --server
```

Дождись внизу окна статуса «подключено».

**Терминал 2 — туннель:**

```bash
cloudflared tunnel --url http://localhost:8090
```

В выводе появится строка вроде:

```
Your quick Tunnel https://random-words-here.trycloudflare.com is now active!
```

Эта ссылка — то, что нужно другу.

---

## 3. Приглашение друга

Отправь другу ссылку `https://....trycloudflare.com` — он открывает её в
браузере и сразу рисует на общей доске. Изменения видны у всех в реальном
времени.

Работает всё: перо, фигуры, текст, цвета, отмена — веб-клиент полный.

---

## 4. Нюансы

- **Порт.** Если доска на другом порту: `./omaboard --server -port 9000` и
  `cloudflared tunnel --url http://localhost:9000`.
- **Ссылка живёт, пока живы оба процесса.** Закрыл omaboard или нажал Ctrl+C
  в cloudflared — доступ пропал. При перезапуске cloudflared ссылка
  **меняется** (это особенность quick-туннелей).
- **Порядок запуска** не важен, но если доска ещё не поднята, по ссылке
  браузер покажет ошибку — просто подожди.
- **Постоянная ссылка.** Нужен аккаунт Cloudflare и именованный туннель
  (`cloudflared tunnel create myboard` + DNS-запись) — делается один раз,
  ссылка больше не меняется. Для разовых игр с друзьям хватает quick-туннеля.

---

## 5. Если что-то не работает

| Симптом | Решение |
|---|---|
| `cloudflared: command not found` | Установи (шаг 1) |
| По локальной ссылке не открывается | Проверь, что доска запущена: `curl http://localhost:8090` → `200` |
| `address already in use` при omaboard | Порт занят — запусти с `-port 9000` и укажи такой же в туннеле |
| Ссылка открылась, но «переподключение…» в статусе | cloudflared и omaboard должны работать одновременно; посмотри вывод терминала cloudflared |
| Хочется проверить без друга | Открой туннель-ссылку в собственном браузере |

---

## 6. Безопасность

Ссылка-туннель работает как ключ: **каждый, кто её узнает, сможет рисовать
на доске и её очищать**. Не выкладывай её в публичные чаты/соцсети. Для
закрытой компании отправляй в личные сообщения; когда игра окончена —
закрой cloudflared (Ctrl+C).
